# Exact obstruction at the projective line at infinity for all `6 x 5` E profiles

Date: 2026-08-26. Status: **PROVED / EXACT-CERT**.

## Theorem

Let `y` be any of the ten representatives

```text
283156, 284244, 285368, 285808,
1873121, 1873123, 1873125, 1877219, 1880980, 1947022
```

from the exact `6 x 5` axis-GES class `E`.  If a real cubic `P(r,s)` strictly
represents `y` on the grid, then the homogeneous leading form

```text
P_3(r,s)=a30 r^3+a21 r^2 s+a12 r s^2+a03 s^3
```

has strictly negative binary-cubic discriminant.  Equivalently, the
projective line at infinity `z=0` is not a split-or-zero legal section of any
strict profile cubic for any E representative.

The same conclusion transports to all forty tables in the ten exact grid
orbits.  This uses only affine grid reflections and global polynomial sign to
transport a statement about cubic cones and discriminants; it does not use or
claim input-complement invariance of `H*`.

Together with the older exact four-axis obstruction, every axis line and the
line at infinity are now excluded exactly.  The diagonal/exterior legal-line
continuum remains open.

## Exact certificate

For a fixed sign table let

```text
K_y={p in R^10 : y_g P(g)>=0 for all 30 grid points g}
```

and let `M p` be the four leading coefficients above.  Each JSON certificate
contains the following rational data.

1. A vector `lambda_g>0` annihilating all signed moments of degree at most
   two.  Hence

   ```text
   sum_g lambda_g y_g P(g) = n . (M p).
   ```

   This is positive for every nonzero member of `K_y`, so the projected cone
   `M(K_y)` is pointed and a nonzero weak representative cannot have zero
   leading form.

2. A complete ray/facet description of `M(K_y)`.  Every stored ray has an
   exact preimage in `K_y`.  For every recomputed facet normal `w`, a
   nonnegative Gordan vector satisfies

   ```text
   A^T mu = M^T w.
   ```

   Thus all facet inequalities are valid on the true projected cone.  Full
   dimension, pointedness, and exhaustive facet recomputation prove equality
   between the true cone and the cone generated by the stored rays.

3. A Pólya certificate for `-Delta`.  In all ten cases the exponent is
   already `N=0`: after positive rational ray rescaling, every coefficient of

   ```text
   -Delta(sum_i t_i ray_i)
   ```

   is nonnegative, and every pure fourth power has positive coefficient.
   Therefore it is strictly positive for every `t_i>=0`, not all zero.

All retained arithmetic is rational.  SciPy only located bases; the verifier
uses `fractions.Fraction` and recomputes every identity.

## Scope

This is an exact obstruction for one projectively legal profile line.  It is
not a proof that an E table has `H*_sym>3`, because non-axis legal lines remain.
It is still less a proof of global `H*>3`: an arbitrary asymmetric raw-bit
three-head representation need not Reynolds-symmetrize while preserving its
pole topology.  No `POIC_2<=3` source is known for an E table.
